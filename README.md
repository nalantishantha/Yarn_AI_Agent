# Yarn Selection AI Agent System

This repository contains the Yarn Selection AI Agent System. 
It helps yarn technicians manually select and approve yarn by providing a ranked shortlist of suitable yarns against order requirements.

## Project Structure

- `frontend/`: React frontend (Vite scaffolded).
- `backend/`: FastAPI backend with LangGraph integration.
- `GEMINI.md`: Detailed project specification and architecture.
